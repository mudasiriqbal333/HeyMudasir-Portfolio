### AVI CHATBOT

Technologies: SvelteJS, LangChain, Twilio, NodeJS, GCP, Python, Scrapping, Quadrant, Firebase.An artificial intelligent chatbot to verify latest and historic news/facts and provide information about scholarly articles, research papers, stocks, etc by providing trusted sources. You can also pre-select the tools, i.e. Arxiv, PubMed, Reddit, VoteSmart and Internet Archive repository to get the information using these tools. Besides that, it lets you limit the sources you wish to use to get the information, for example, if you want to get the information from just BBC and CNN, you can pre-define these sources and it will only retrieve info from these sources. Moreover, it stores the chat histories and chats (just like ChatGPT and Gemini).

### AVI CHATBOT


### The Challenge:

Enhancing User Interaction and Information Retrieval | The client approached us with the need for an advanced chatbot that could engage users in natural language conversations and provide accurate, sourced information. Existing chatbots often lacked advanced browsing capabilities, multilingual support, and customization options. The client sought a solution that could serve as a reliable virtual assistant, offering a seamless user experience across various languages and incorporating advanced features like web browsing and text-to-speech.


### The Solution:

Developing AVI Chatbot, An Intelligent Virtual Assistant | We created AVI Chatbot, an innovative solution designed to enhance user interaction and information retrieval. The chatbot features a sidebar on the left and a chat interface on the right, providing a user-friendly and intuitive design.


### Advanced NLP Model and Customised Transformer Architecture

AVI Chatbot leverages an advanced NLP (Natural Language Processing) model, built upon a customised transformer architecture. This model, tailored specifically for AVI Chatbot’s requirements, was trained on a vast dataset to understand and generate natural language responses with high accuracy.


### Dynamic Information Retrieval

The chatbot has access to the internet, enabling real-time web browsing and information retrieval. This capability allows AVI Chatbot to fetch up-to-date and relevant information in response to user queries, ensuring comprehensive and reliable responses.


### Customizable Knowledge Base

Users can customise and expand AVI Chatbot’s knowledge base by adding new sources or refining existing ones. This feature enhances the chatbot’s ability to provide tailored responses based on specific user needs and preferences.


### Multilingual Support and Accessibility

AVI Chatbot supports multiple languages and includes text-to-speech functionality, enhancing accessibility for users globally. This multilingual capability ensures that users can interact with the chatbot in their preferred language, further improving user experience and engagement.


### User-Centric Design

The chatbot interface is designed to prioritise user experience, with intuitive navigation and responsive interaction capabilities. AVI Chatbot aims to provide a seamless and efficient virtual assistant experience, catering to both casual users and those seeking detailed information.


### The Results:

Advancing Beyond Typical AI Solutions | AVI Chatbot is made to revolutionise user interaction and information retrieval. The chatbot’s advanced features and user-friendly design are expected to significantly improve user experience and satisfaction.

Enhanced User Engagement: The natural language processing and intuitive interface are expected to lead to higher user engagement and satisfaction.

Accurate Information Retrieval: The web browsing and source listing capabilities are anticipated to provide users with reliable and accurate information.

Broader Accessibility: Multilingual support and text-to-speech features are expected to make the chatbot accessible to a wider audience.

Customizability: The ability to customise and add sources ensures that the chatbot remains relevant and useful to users.
