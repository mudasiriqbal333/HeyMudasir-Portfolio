Images are in `public/assets/<slug>/` and are served at `/assets/<slug>/<file>`.

Every image was opened and identified by eye on 2026-09-23: all 114 sit in the right project. Projects whose notes have a Near-duplicates section contain the same screen more than once, usually a smaller copy from the second document.

`assets-manifest.json` (moved here from `public/assets/manifest.json`, where it was being published with the site) records which image of the Word documents each extracted file came from. It is a record only: no code reads it, and it was never updated for REHQ or for the files added to Jarvis and TOW123 later. The current pixel size of every picture is in `app/_data/media-sizes.json`, which `npm run sizes` writes from the files.
